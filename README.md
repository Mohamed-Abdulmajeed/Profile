# Personal Portfolio

## Overview
Professional portfolio website to showcase skills, experience, and projects in a clear and polished way. The site highlights technical background, selected work, and provides simple ways for visitors or potential clients to get in touch.

## Sections
- **About:** A short personal introduction and a link to download the CV.
- **Skills:** A concise list of technical skills and tools.
- **Projects:** Showcase of projects with links and demo pages where available.
- **Contact:** Contact form or direct contact links (email and social profiles).

## Built With
- HTML, CSS, JavaScript
